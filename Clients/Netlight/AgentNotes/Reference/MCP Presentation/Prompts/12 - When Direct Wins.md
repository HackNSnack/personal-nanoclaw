# Slide 12 — When Direct Wins

## Prompt for Claude + PowerPoint

```
Create a slide following the design guidelines in [[Clients/Netlight/AgentNotes/Reference/netlight-design-guidelines]].

**Slide content:**
- Title: "When Direct Wins"
- Subtitle: "MCP isn't always the answer"

**Body — Scenarios where direct integration is better:**

Present as a checklist or decision criteria:

✓ **Single application**
  "You're building one AI app, not a platform"

✓ **Few, stable tools**
  "2-3 integrations that rarely change"

✓ **Performance-critical paths**
  "Every millisecond matters — no room for extra hops"

✓ **Highly specialized behavior**
  "The tool needs deep integration with your LLM's specific features"

✓ **Rapid prototyping**
  "You need something working in an hour, not a day"

**Optional closing line:**
"If this sounds like your situation — skip MCP. Keep it simple."

**Layout guidance:**
- Checklist format with checkmarks or bullet points
- Clean, scannable — audience should quickly assess "is this me?"
- White background
- Consider using Yellow (#FFF400) sparingly for checkmarks to make them pop
- Or keep it purple-monochrome for consistency
- Generous whitespace
- Proxima Nova font
- Tone: pragmatic, not defensive
```

## Purpose

Earn credibility by not overselling. Audience thinks: "Okay, this person is being honest with me."

## Presenter notes

- "If you're nodding at most of these — direct integration is probably fine"
- "MCP shines when you outgrow this list"
- Transition: "But what's the actual trade-off? Let's look at it side by side."
