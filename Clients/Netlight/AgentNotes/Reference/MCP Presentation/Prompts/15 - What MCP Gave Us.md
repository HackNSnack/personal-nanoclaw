# Slide 15 — What MCP Gave Us

## Prompt for Claude + PowerPoint

```
Create a slide following the design guidelines in [[Clients/Netlight/AgentNotes/Reference/netlight-design-guidelines]].

**Slide content:**
- Title: "What MCP Gave Us"
- Subtitle: "The wins"

**Body — Concrete benefits (as cards, list, or icons + text):**

1. **One integration, all AI tools**
   "We built one MCP server. It works with Claude, ChatGPT, Copilot — whatever customers use."

2. **We didn't have to pick sides**
   "No SDKs for every AI platform. No vendor lock-in. One standard."

3. **Faster customer onboarding**
   "Customers connect in minutes, not weeks. No custom integration work."

4. **Accessible to less technical users**
   "Non-developers can plug in their own LLMs and start querying data immediately."

5. **Future-proof**
   "New AI tool next year? It'll probably support MCP. We're already ready."

**Layout guidance:**
- 5 benefit cards or a clean numbered/bulleted list
- Each benefit: bold headline + one-line explanation
- Use icons if helpful (plug, clock, users, shield, rocket)
- Positive tone — these are wins, make them feel like wins
- White background
- Accent with Netlight Purple or Yellow for emphasis
- Proxima Nova font
- Keep it scannable — not a wall of text
```

## Purpose

Show the real payoff. Audience should think: "That's compelling — I want that."

## Presenter notes

- Pick 2-3 to emphasize verbally
- "The one that surprised us most: non-technical users. They just... connected and started asking questions."
- "We didn't have to build a ChatGPT plugin AND a Claude integration AND a Copilot extension. One server."
- Let enthusiasm show — these are genuine wins
