# Slide 1 — Title Slide

## Prompt for Claude + PowerPoint

```
Create a title slide for a presentation following the design guidelines in [[Clients/Netlight/AgentNotes/Reference/netlight-design-guidelines]].

**Slide content:**
- Title: "MCP; 2025's hottest AI-topic"
- Subtitle: "What is MCP, and why do we use it?"
- Presenter: Mathias Pettersen
- Company: Netlight
- Date: 14 April 2026

**Layout guidance:**
- Clean, bold composition with strong hierarchy
- Title should be the dominant element
- Subtitle slightly smaller, clearly secondary
- Presenter name, company, and date in a subtle footer or lower section
- Use Netlight's primary purple (#A29AFF) as the accent color
- White/bright background
- Include the Netlight logo (primary logotype) — positioned appropriately (e.g., bottom corner or header)
- Proxima Nova font throughout
- No clutter — confident and minimal
```

## Purpose

Set the stage. First impression — bold, professional, clearly Netlight-branded.
