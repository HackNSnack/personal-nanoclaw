# Slide 21 — Build or Adopt?

## Prompt for Claude + PowerPoint

```
Create a slide following the design guidelines in [[Clients/Netlight/AgentNotes/Reference/netlight-design-guidelines]].

**Slide content:**
- Title: "Build or Adopt?"
- Subtitle: "Two ways to join the ecosystem"

**Body — Two paths, both valid:**

**Path A: Adopt**
"Use existing MCP servers"

- 1,000+ servers already available
- GitHub, Slack, Jira, databases, and more
- Plug them into your AI tools today
- Benefit from community maintenance

Best for: "You want AI tools to access external services"

**Path B: Build**
"Create an MCP server for your product"

- Expose your API to the AI ecosystem
- Let customers connect with their preferred AI tools
- One server, infinite reach
- Become part of the standard

Best for: "You want others to access YOUR services via AI"

**Closing line (centered, below both paths):**
"Either way — you're contributing to a shared ecosystem."

**Layout guidance:**
- Two equal columns or cards: Adopt (left) vs Build (right)
- Each path gets a bold header, bullet points, and "best for" line
- Visual balance — neither path is lesser
- Could use icons: download/plug icon for Adopt, wrench/hammer for Build
- White background
- Netlight Purple for headers/accents
- Proxima Nova font
- Encouraging, action-oriented tone
```

## Purpose

Give them a clear next step based on their situation. Everyone leaves with something to do.

## Presenter notes

- "If you're a consumer of services — adopt. There are servers for almost everything."
- "If you're a provider — build. This is how you meet your users where they are."
- "We did both. We use MCP servers for our internal tools. We built one for our customers."
- "The ecosystem grows either way."
