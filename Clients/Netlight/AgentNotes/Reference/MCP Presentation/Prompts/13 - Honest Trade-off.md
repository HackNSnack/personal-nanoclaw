# Slide 13 — The Honest Trade-off

## Prompt for Claude + PowerPoint

```
Create a slide following the design guidelines in [[Clients/Netlight/AgentNotes/Reference/netlight-design-guidelines]].

**Slide content:**
- Title: "The Honest Trade-off"
- Subtitle: "What you're choosing between"

**Body — Comparison table:**

| Dimension        | Direct Integration      | MCP                        |
|------------------|-------------------------|----------------------------|
| **Control**      | Full                    | Standardized               |
| **Simplicity**   | Fewer moving parts      | More infrastructure        |
| **Speed**        | Lower latency           | Protocol overhead          |
| **Reusability**  | App-specific            | Cross-app, cross-vendor    |
| **Ecosystem**    | Build everything        | 1000+ servers available    |
| **Scalability**  | M×N integrations        | M+N integrations           |
| **Future-proof** | Tied to your stack      | Industry standard          |

**Optional visual alternative:**
Instead of a table, show as a spectrum/slider:

Control ◄─────────────► Ecosystem
Simplicity ◄─────────────► Scalability
Speed ◄─────────────► Reusability

With "Direct" on the left end, "MCP" on the right end.

**Layout guidance:**
- Table should be clean and readable
- Alternate row shading optional (Light Purple #C6C6FF for alternate rows)
- Headers in Dark Purple (#6664F1)
- White background
- If using spectrum, make it visual with dots or markers showing where each approach sits
- No winner highlighted — this is neutral presentation
- Proxima Nova font
```

## Purpose

Crystallize the choice. Not "MCP good, direct bad" — but "here's what you're trading."

## Presenter notes

- Walk through 2-3 key rows: "Control vs ecosystem. Speed vs reusability."
- "Neither is wrong — it depends on your context"
- Transition to Act 4: "So what did we choose? And what did we learn?"
