# Slide 27 — Two Plausible Futures

## Prompt for Claude + PowerPoint

```
Create a slide following the design guidelines in [[Clients/Netlight/AgentNotes/Reference/netlight-design-guidelines]].

**Slide content:**
- Title: "Two Plausible Futures"
- Subtitle: "We genuinely don't know which one wins"

**Body — Fork diagram (SVG/timeline style):**

Left side: horizontal timeline with two markers:
- "MCP launches" (Nov 2024)
- "Agents read APIs" (2025)

Center: dashed vertical line labeled "NOW" with a large "?" at the fork point

Right side: two diverging paths:
- **Upper path (purple):** "Future A: Standards win" — "MCP becomes the lingua franca"
  - Purple background card
- **Lower path (orange/amber):** "Future B: Generation wins" — "Every tool ephemeral & bespoke"
  - Yellow/amber background card

**Footer (italic, centered, muted):**
"The answer probably depends on how good agents get at trust and verification — and we're not there yet."

**Layout guidance:**
- SVG diagram centered, clean and readable
- Timeline flows left to right
- Fork is the visual focal point — the "?" should draw the eye
- Both futures given equal visual weight — neither is favored
- White background
- Netlight Purple for Future A, warm amber/orange for Future B
- Proxima Nova font
- Open, uncertain tone — the question IS the point
```

## Purpose

Leave the audience with a genuinely open question. Don't resolve it — the uncertainty is the message. This is a strong Q&A anchor.

## Presenter notes

- "We genuinely don't know. Both paths are being built right now."
- "If you're building a product today — which future are you designing for?"
- "The timeline grounds it: we're at the fork TODAY, making real choices"
- Don't try to answer it. Let the audience sit with the question.
- Good Q&A prompt: "Which future are you building for right now?"
