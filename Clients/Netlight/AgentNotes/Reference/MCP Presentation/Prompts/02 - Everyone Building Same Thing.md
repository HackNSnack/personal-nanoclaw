# Slide 2 — "Everyone's Building the Same Thing"

## Prompt for Claude + PowerPoint

```
Create a slide following the design guidelines in [[Clients/Netlight/AgentNotes/Reference/netlight-design-guidelines]].

**Slide content:**
- Title: "Everyone's Building the Same Thing"
- Body content (choose one or combine):
  
  Option A — Anecdote:
  "Last year, I talked to three different teams at three different companies.
  All of them were building Slack integrations for their AI assistant.
  From scratch. Again."
  
  Option B — Stat:
  "73% of enterprises report building custom AI integrations that already exist elsewhere."
  (Note: placeholder stat — replace with real data if available)
  
  Option C — Question hook:
  "How many times have you written code to connect an LLM to your database?
  To Slack? To your calendar? To your docs?"

**Layout guidance:**
- Title prominent at top
- Body text centered or left-aligned, with breathing room
- If using the anecdote, consider slight emphasis (bold or color) on "From scratch. Again."
- If using the question hook, each question could be on its own line for rhythm
- White background, purple accent for emphasis
- Minimal — let the words land
- No images needed, but subtle graphic element (e.g., a thin purple line or shape) acceptable
- Proxima Nova font
```

## Purpose

Hook the audience with recognition. They've seen this problem — or lived it. Creates buy-in before introducing the solution.

## Notes for presenter

- Deliver this conversationally
- Pause after the punchline ("From scratch. Again." or the last question)
- Goal: head nods in the audience
