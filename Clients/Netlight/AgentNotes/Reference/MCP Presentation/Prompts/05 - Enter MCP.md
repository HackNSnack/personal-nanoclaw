# Slide 5 — Enter MCP

## Prompt for Claude + PowerPoint

```
Create a slide following the design guidelines in [[Clients/Netlight/AgentNotes/Reference/netlight-design-guidelines]].

**Slide content:**
- Title: "Enter MCP"
- Subtitle: "Model Context Protocol"

**Body — the pitch in three beats:**

1. **Definition (one line):**
   "An open standard for connecting AI applications to external tools and data."

2. **Origin:**
   "Created by Anthropic, November 2024"

3. **Current status:**
   "Now governed by the Linux Foundation's Agentic AI Foundation"
   "Backed by Anthropic, OpenAI, Google, Microsoft, and others"

**Layout guidance:**

- Title large and bold at top — this is the reveal moment
- Subtitle "Model Context Protocol" directly beneath, slightly smaller
- Definition prominently displayed — this is the core message
- Origin and status as secondary info below, smaller but readable
- Consider a visual element: the MCP logo if available, or a simple icon representing connection/protocol (e.g., plug, network node)
- White background
- Use Netlight Purple (#A29AFF) for accent/emphasis
- Generous whitespace — let it breathe
- Proxima Nova font

**Tone:**
This slide should feel like an answer arriving. Clean, confident, authoritative.
```

## Purpose

The pivot from problem to solution. Audience should think: "Okay, what's this?"

## Presenter notes

- Pause slightly before revealing the title — builds anticipation
- Emphasize "open standard" — not proprietary, not locked in
- The Linux Foundation backing adds credibility — mention it verbally
- Don't over-explain here; the next slides will unpack how it works
