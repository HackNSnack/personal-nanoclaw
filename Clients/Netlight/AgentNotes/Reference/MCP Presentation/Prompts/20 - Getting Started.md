# Slide 20 — Getting Started

## Prompt for Claude + PowerPoint

```
Create a slide following the design guidelines in [[Clients/Netlight/AgentNotes/Reference/netlight-design-guidelines]].

**Slide content:**
- Title: "Getting Started"
- Subtitle: "Three steps to try MCP"

**Body — Three concrete steps:**

**1. Try an existing server**
"Install a server from the registry. Connect it to Claude Desktop."
"5 minutes to see MCP in action."
→ github.com/modelcontextprotocol/servers

**2. Read the spec**
"Understand the architecture: hosts, clients, servers, tools."
"It's well-documented and readable."
→ modelcontextprotocol.io

**3. Build your own**
"Start with a simple read-only server. A few tools, one data source."
"SDKs available in Python, TypeScript, and more."
→ modelcontextprotocol.io/docs/getting-started

**Resources (footer or sidebar):**
- Official docs: modelcontextprotocol.io
- GitHub MCP Registry: github.com/modelcontextprotocol
- Example servers: github.com/modelcontextprotocol/servers

**Layout guidance:**
- Three numbered steps, visually distinct
- Each step: bold action + one-line explanation + URL
- Could use icons (download, book, wrench) for each step
- URLs should be visible but not dominant
- White background
- Netlight Purple accents
- Clean and actionable — not overwhelming
- Proxima Nova font
```

## Purpose

Remove friction. Audience should think: "I could try this today."

## Presenter notes

- "Step 1 takes five minutes. Seriously. Try it."
- "The spec is surprisingly readable — not a 200-page standards doc"
- "If you're a provider like us, start with read-only. Get it working, then add write operations."
- "The SDKs do most of the heavy lifting"
