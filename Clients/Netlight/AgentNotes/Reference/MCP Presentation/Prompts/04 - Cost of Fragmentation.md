# Slide 4 — The Cost of Fragmentation

## Prompt for Claude + PowerPoint

```
Create a slide following the design guidelines in [[Clients/Netlight/AgentNotes/Reference/netlight-design-guidelines]].

**Slide content:**
- Title: "The Cost of Fragmentation"

**Body — Four key costs (presented as a 2×2 grid or vertical list with icons):**

1. **Duplicated Effort**
   "Teams rebuild the same Slack integration, the same GitHub connector, the same Jira sync — over and over."

2. **Inconsistent Security**
   "Each integration handles auth differently. Some store tokens safely. Some don't."

3. **No Reuse**
   "Built a great GitHub tool for your chatbot? Good luck using it in VS Code."

4. **Maintenance Burden**
   "APIs change. Now you're patching 12 integrations instead of one."

**Layout options:**

Option A — 2×2 Grid:
- Four boxes/cards arranged in a grid
- Each with a short bold title + one-line description
- Icons optional (wrench, shield, recycle, tools)

Option B — Vertical list with icons:
- Left-aligned list
- Icon | Bold title | Description on each row
- More breathing room between items

**Visual guidance:**
- White background
- Use Dark Purple (#6664F1) for titles/icons
- Body text in black
- Cards/boxes can have Light Purple (#C6C6FF) background or subtle border
- Keep it scannable — audience should grasp all four in seconds
- Proxima Nova font
- No clutter — the words carry the weight
```

## Purpose

Translate the abstract "M×N problem" into real consequences they've felt. Builds urgency before introducing the solution.

## Presenter notes

- Don't read all four aloud — let them scan
- Pick one to emphasize: "The security one keeps me up at night"
- Transition: "So what if there was a standard?"
