# Slide 18 — The Verdict

## Prompt for Claude + PowerPoint

```
Create a slide following the design guidelines in [[Clients/Netlight/AgentNotes/Reference/netlight-design-guidelines]].

**Slide content:**
- Title: "The Verdict"
- Subtitle: "It's not either/or"

**Body — The core insight:**

**Main statement (large, prominent):**
"Use MCP to be accessible. Use direct to be excellent."

**Supporting framing (below, smaller):**

**MCP = Distribution strategy**
- Meet users where they already are
- Self-serve access to your capabilities
- Ecosystem participation and reach

**Direct = Product experience strategy**
- Own the experience when users come to you
- Control prompts, flow, and quality
- Optimized for accuracy and reliability

**Closing line:**
"MCP expands your reach. Direct protects your quality. Run both."

**Layout guidance:**
- Main statement should be the visual anchor — large, bold, centered
- Two-column layout below for MCP vs Direct framing
- Or stacked cards if space is tight
- White background
- Use Netlight Purple (#A29AFF) for emphasis on key phrases
- Keep it clean — this is the "aha" moment of the experience section
- Proxima Nova font
- Confident, declarative tone
```

## Purpose

Deliver the key takeaway from our experience. Not a cop-out "it depends" — a clear framework for thinking about it.

## Presenter notes

- Pause before revealing the main statement
- "This is what we learned after running both in production"
- "MCP isn't replacing direct integration. They serve different purposes."
- "If you only have one touchpoint and control the full experience — direct might be enough"
- "If you want to reach users wherever they are — MCP is how you do that"
- "We do both. And that's the point."
