# Slide 8 — M+N, Not M×N

## Prompt for Claude + PowerPoint

```
Create a diagram slide following the design guidelines in [[Clients/Netlight/AgentNotes/Reference/netlight-design-guidelines]].

**Slide content:**
- Title: "M+N, Not M×N"
- Subtitle: "Build once, connect to everything"

**Diagram specification:**

Same elements as Slide 3, but with MCP in the middle:

Left side — AI Applications (same 4):
1. Claude Desktop
2. Internal Agent
3. VS Code + Claude
4. Support Bot

CENTER — MCP (new element):
- A central box or hub labeled "MCP"
- Visually distinct: use Netlight Purple (#A29AFF) fill or bold border
- Could be a hexagon, rounded rectangle, or hub shape

Right side — Tools/Services (same 3):
1. GitHub
2. Jira
3. Slack

Connections:
- Draw ONE line from each app to the MCP hub (4 lines)
- Draw ONE line from MCP hub to each tool (3 lines)
- Total: 7 clean, parallel lines
- Lines should be neat and organized — stark contrast to Slide 3

Below the diagram:
- Text: "4 apps + 3 tools = 7 integrations"
- Optional comparison: "Not 12. Seven."
- Optional: "Add a new tool? Just one more server."

**Layout guidance:**
- Three-column flow: Apps → MCP → Tools
- MCP hub is the visual anchor, slightly larger/bolder
- Lines are clean, evenly spaced, satisfying
- Use Netlight Purple for MCP hub and connection lines
- App/tool boxes in Dark Purple (#6664F1) or neutral
- White background
- This slide should feel like relief after Slide 3's chaos
- Proxima Nova font
```

## Purpose

The visual payoff. Audience sees the same components, but now it's clean. The "aha" moment.

## Presenter notes

- Pause and let them compare mentally to Slide 3
- "Same apps. Same tools. But now: 7 integrations instead of 12."
- "Add a fifth tool? One more line — not four."
- "This is why MCP matters."
