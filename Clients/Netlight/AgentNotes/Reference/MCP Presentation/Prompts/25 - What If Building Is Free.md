# Slide 25 — What If Building Is Free?

## Prompt for Claude + PowerPoint

```
Create a slide following the design guidelines in [[Clients/Netlight/AgentNotes/Reference/netlight-design-guidelines]].

**Slide content:**
- Title: "What If Building Is Free?"
- Subtitle: "The cost of a custom integration is collapsing"

**Body — Cost collapse timeline (left-aligned, stacked vertically):**

Each line: bold time on the left, description on the right

- **10 days** — 2020 — write it from scratch
- **10 hours** — 2023 — AI-assisted development
- **10 minutes** — 2025 — prompt the right LLM

**Punchline (centered, below timeline, bold):**
"If M×N costs nothing — does the problem still exist?"

**Layout guidance:**
- Timeline entries stacked vertically with generous spacing
- Time values large and prominent (Netlight Purple Dark)
- Description text smaller, regular weight
- Punchline separated with whitespace, large and bold
- White background
- Proxima Nova font
- Thought-provoking, almost confrontational tone
```

## Purpose

Challenge the fundamental assumption behind MCP. The entire M×N argument rests on integration cost being non-trivial. If agents can generate bespoke connectors in minutes, the calculus changes.

## Presenter notes

- "We just spent 20 minutes talking about why MCP solves M×N. But what if M×N becomes free?"
- "This isn't hypothetical — agents today can scaffold a working API integration in minutes"
- "The question shifts from 'build vs adopt' to 'persist vs generate'"
- Pause after the punchline. Let it land.
