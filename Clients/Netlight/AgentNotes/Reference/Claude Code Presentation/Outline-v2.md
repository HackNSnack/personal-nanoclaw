# Claude Code & AI Tooling — Alternate Slide Outline (v2)

**Slides:** 19
**Estimated duration:** ~30 minutes
**Structural approach:** Demo-driven — front-load a live/recorded demo, then unpack what the audience saw.

---

### 01 — Title
- **Type:** title
- **Purpose:** Set the stage
- **Key message:** Grounded, practical talk about AI tooling
- **Content:** "Claude Code & AI Tooling — What Actually Works" / Speaker, date, Netlight

### 02 — The Noise
- **Type:** content
- **Purpose:** Acknowledge the hype
- **Key message:** The AI narrative is loud — most of it hasn't changed your Monday morning
- **Content:** Collage of headlines. End with: "How much of this changed your last sprint?"

### 03 — But Something Did Change
- **Type:** transition
- **Purpose:** Pivot to acknowledging real shift
- **Key message:** AI tooling is genuinely useful — just not how headlines suggest
- **Content:** "Something *did* change." — large, centered. Below: "Let me show you."

### 04 — Live Demo: A Real Task
- **Type:** content (demo)
- **Purpose:** Show don't tell — real Claude Code workflow before any explanation
- **Key message:** This is what it actually looks like
- **Content:** Live or recorded demo (~5-7 min). Relatable task. Show: launch, context, file reading, proposed changes.

### 05 — What Just Happened
- **Type:** content
- **Purpose:** Unpack the demo
- **Key message:** The tool read context, reasoned, proposed changes — you stayed in control
- **Content:** 3-step recap: (1) Described task, (2) Tool navigated code, (3) Proposed changes for review.

### 06 — Where This Sits
- **Type:** diagram
- **Purpose:** Place Claude Code in the tooling spectrum
- **Key message:** What you just saw is the "agentic" end of the spectrum
- **Content:** Spectrum: Autocomplete → Inline Copilot → Agentic Tool. Highlight "Agentic."

### 07 — The Spectrum in Practice
- **Type:** comparison
- **Purpose:** Mental model for when to use which category
- **Key message:** Different tools for different friction points
- **Content:** Autocomplete ("finishing your sentence"), Copilot ("pair programmer, one file"), Agentic ("junior dev who's read the whole repo").

### 08 — Where It Genuinely Helps
- **Type:** list
- **Purpose:** Concrete wins
- **Key message:** Specific categories where this reliably adds value
- **Content:** Multi-file refactors, boilerplate, exploring codebases, test first drafts, mechanical changes.

### 09 — Where It Falls Short
- **Type:** list
- **Purpose:** Build trust through honesty
- **Key message:** Know the failure modes
- **Content:** Hallucinated APIs, architecture decisions, business context, security edge cases, "500 lines perfect then invents a function."

### 10 — The Trust Model
- **Type:** content
- **Purpose:** Reframe as collaboration, not delegation
- **Key message:** Fast first drafts, not autonomous decisions
- **Content:** "Very fast colleague who's read a lot of code but doesn't know your system. You wouldn't merge their PR without reviewing it."

### 11 — Workflow: Writing Tests
- **Type:** content
- **Purpose:** First concrete try-it-tomorrow workflow
- **Key message:** AI handles scaffolding, you focus on edge cases
- **Content:** AI generates 80% of test cases → you add tricky business logic tests.

### 12 — Workflow: Codebase Exploration
- **Type:** content
- **Purpose:** Second workflow — resonates with project-switchers
- **Key message:** AI navigates and summarizes faster than grep
- **Content:** "How does auth work?" → reads, traces, summarizes. Day → minutes.

### 13 — Workflow: Mechanical Refactors
- **Type:** content
- **Purpose:** Third workflow — the tedious category
- **Key message:** Mechanical repetitive changes are exactly where AI fits
- **Content:** Rename across 20 files, migrate API, update imports.

### 14 — What Changes About Your Job
- **Type:** transition
- **Purpose:** Pivot to the deeper shift
- **Key message:** From writing every line to directing and reviewing
- **Content:** "Less typing. More thinking."

### 15 — What You Spend Your Attention On
- **Type:** content
- **Purpose:** Make the shift personal and concrete
- **Key message:** Tedious gets faster → more time on interesting problems
- **Content:** Before/after attention split (illustrative). More thinking/designing, less writing/editing.

### 16 — The Skeptic's Question
- **Type:** content
- **Purpose:** Address the unspoken concern
- **Key message:** AI replaces typing, not thinking — demands more judgment
- **Content:** "If AI writes the code, what's the developer for?" → "Making the decisions the tool can't."

### 17 — One Thing This Week
- **Type:** content
- **Purpose:** Low-stakes call to action
- **Key message:** Don't overhaul — just try one thing
- **Content:** "Pick one repetitive task. Try it with AI next week."

### 18 — Three Takeaways
- **Type:** list
- **Purpose:** Reinforce key messages
- **Content:** (1) Real and useful — not magic. (2) Faster iteration, not autonomous coding. (3) Start with one thing.

### 19 — Thank You / Q&A
- **Type:** closing
- **Content:** Thank you / speaker / contact / Questions?
