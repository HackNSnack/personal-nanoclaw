# EuroBonus Best Case Value — Sale Awards + Companion Ticket

> How much is 1 EuroBonus point really worth when you combine award sales (poengrabatt) with a 2-for-1 Companion Ticket? This document recalculates the effective EB-to-NOK ratio used in the shopping and grocery analysis documents under best-case conditions.

---

## Methodology

The existing documents assume:
- **1 EB ≈ 0.10 NOK** (standard economy redemption: 30,000 EB ≈ 3,000 NOK)
- **1 EB ≈ 0.20 NOK** (with 2-for-1 Companion Ticket)

These are based on **full-price award bookings**. SAS regularly runs *Poengrabatt* (point bargain sales) that reduce award prices by 20–50 %. When combined with a Companion Ticket, the effective value per point can be significantly higher.

### How the Companion Ticket works

- The primary traveller pays the full award price in points
- The companion travels for **0 points** (only taxes/fees)
- Total points for 2 people = **1× the award price**
- Per-person points cost = award price ÷ 2

### How award sales (Poengrabatt) work

SAS runs award sales ~4-6 times per year, typically lasting 5–7 days with travel windows 3–6 months out. Gold/Diamond members get early access.

| Region | Typical discount |
|--------|-----------------|
| Scandinavia domestic | 50 % off |
| Europe | 30–40 % off |
| USA/Asia (long haul) | 20 % off |

Sales apply to SAS Go and SAS Plus. Business Class (SAS Business) is almost never included.

**Sources:** insideflyer.no (2016–2019 coverage of 10+ SAS Poengrabatt events), SAS official award charts.

### Can you stack Companion Ticket + award sale?

The evidence is inconclusive. No explicit prohibition is documented, and there are isolated forum reports of successful CT bookings during sale windows ``(insideflyer.no forum)``. However, it is likely that the CT applies to the **standard award price** and award sales apply to **non-CT bookings**.

This document covers **both scenarios** so you can evaluate the range.

## Scenario A: Award Sale Only (No Companion Ticket)

| Calculation | Europe (40 % sale) | USA (20 % sale) | Asia / SkyTeam (20 % sale) |
|-------------|-------------------|-----------------|---------------------------|
| Cash price (typical RT) | 3,000 NOK | 8,000 NOK | 12,000 NOK |
| Standard award | 30,000 EB | 80,000 EB | 90,000 EB |
| Sale discount | 40 % | 20 % | 20 % |
| Sale award price | **18,000 EB** | **64,000 EB** | **72,000 EB** |
| EB value (standard) | 0.10 NOK/EB | 0.10 NOK/EB | 0.13 NOK/EB |
| **EB value (sale)** | **0.17 NOK/EB** | **0.125 NOK/EB** | **0.17 NOK/EB** |
| Value uplift vs standard | **+70 %** | **+25 %** | **+30 %** |

### Step-by-step: Europe (Oslo → Paris), 40 % sale

```
Cash price         = 3,000 NOK
Standard award     = 30,000 EB
Sale discount      = 40 %
Sale award         = 30,000 × (1 − 0.40) = 18,000 EB
EB value (sale)    = 3,000 ÷ 18,000 = 0.17 NOK/EB
```

## Scenario B: Companion Ticket Only (No Award Sale)

| Calculation | Europe | USA | Asia |
|-------------|--------|-----|------|
| Cash price (2 people) | 6,000 NOK | 16,000 NOK | 24,000 NOK |
| Standard award (1 person) | 30,000 EB | 80,000 EB | 90,000 EB |
| CT: total points (2 people) | 30,000 EB | 80,000 EB | 90,000 EB |
| CT: points per person | 15,000 EB | 40,000 EB | 45,000 EB |
| **EB value (CT only)** | **0.20 NOK/EB** | **0.20 NOK/EB** | **0.27 NOK/EB** |

### Step-by-step: Europe with CT only

```
Cash per person     = 3,000 NOK
Normal award        = 30,000 EB
CT: total for 2     = 30,000 EB (1× award)
Per person points   = 30,000 ÷ 2 = 15,000 EB
EB value (per pers) = 3,000 ÷ 15,000 = 0.20 NOK/EB
```

## Scenario C: Best Case — Combined Award Sale + Companion Ticket

### If CT can be applied to a sale-priced award

| Calculation | Europe (40 % sale + CT) | USA (20 % sale + CT) | Asia (20 % sale + CT) |
|-------------|------------------------|---------------------|----------------------|
| Cash price (2 people) | 6,000 NOK | 16,000 NOK | 24,000 NOK |
| Sale award (1 person) | 18,000 EB | 64,000 EB | 72,000 EB |
| CT: total points (2 people) | 18,000 EB | 64,000 EB | 72,000 EB |
| Points per person | 9,000 EB | 32,000 EB | 36,000 EB |
| **EB value per person** | **0.33 NOK/EB** | **0.25 NOK/EB** | **0.33 NOK/EB** |

### If CT cannot be applied to a sale (must choose best option)

Pick the better of:
1. **Sale only:** 18,000 EB × 1 person = 18,000 per person
2. **CT only:** 30,000 EB ÷ 2 = 15,000 per person

Europe: CT-only (15,000 EB, 0.20 NOK/EB) beats sale-only (18,000 EB, 0.17 NOK/EB).

| Calculation | Europe | USA | Asia |
|-------------|--------|-----|------|
| Best option | CT only | CT only | CT only |
| Points per person | 15,000 EB | 40,000 EB | 45,000 EB |
| EB value (per person) | **0.20 NOK/EB** | **0.20 NOK/EB** | **0.27 NOK/EB** |

**Conclusion:** Even without stacking, the CT alone already beats typical award sale pricing on a per-person basis for most routes (because 2-for-1 = 50 % off, while sales max out at 40 % off for Europe). The exception would be a 50 % sale (domestic Scandinavia) where sale matches CT.

Use these as upper-bound EB value estimates:

| Assumption | EB value | When to use |

## Summary

| Metric | Current assumption | Conservative best | Optimistic best |
|--------|-------------------|-------------------|-----------------|
| EB value | 0.10 kr | 0.20 kr | 0.33 kr |
| Kiwi effective price (per 100 kr) | 97.15 kr | 94.30 kr | 90.59 kr |
| Kiwi vs Rema gap | 1.35 kr | 2.70 kr | 4.46 kr |
| Kiwi vs Coop gap | 0.35 kr | 1.70 kr | 4.46 kr |

**Real-world takeaway:** Even at the conservative best case (1 EB = 0.20 kr, using the CT ), the effective savings from shopping at Kiwi with Trumf are meaningful. The **optimistic best case** (sale + CT stacked) nearly doubles your savings — but requires both a Poengrabatt event *and* a CT, which may not align with when you need to travel.
